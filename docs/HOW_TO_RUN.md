# Руководство по запуску и демонстрации на защите

## 1. Быстрый старт на компьютере

### Шаг 1: Открытие терминала в папке проекта
Откройте PowerShell или командную строку в папке `E:\diploma-bas-platform`.

### Шаг 2: Установка зависимостей (один раз)
```powershell
pip install -r requirements.txt
```

### Шаг 3: Запуск веб-интерфейса
```powershell
python main.py
```
* После запуска автоматически откроется браузер по адресу: `http://127.0.0.1:8000`.

---

## 2. Варианты демонстрации на защите перед комиссией

### Сценарий А: Презентация через интерактивный Веб-Дашборд
1. Откройте страницу `http://127.0.0.1:8000`.
2. Объясните комиссии структуру матрицы MITRE ATT&CK на экране.
3. Нажмите кнопку **«Запустить полный аудит атак»**.
4. В реальном времени терминал справа начнет выводить пошаговые этапы эмуляции атак (закрепление, реестр, планировщик, UAC, дамп памяти, DNS-эксфильтрация).
5. Покажите комиссии итоговый расчет **Security Posture Score** (например, 30% или 70%).
6. Нажмите **«Выгрузить отчет для ВКР (HTML)»** и покажите сформированный профессиональный отчет аудита с рекомендациями по устранению уязвимостей по стандартам ФСТЭК.

### Сценарий Б: Демонстрация в чистой консоли (CLI)
Если комиссия просит показать работу через терминал операционной системы без браузера:
```powershell
python main.py --cli
```
* Программа выведет аудит прямо в командную строку и сохранит отчет `diploma_audit_report.html` в текущую папку.

---

## 3. Как получить высокий балл и пройти Антиплагиат:
1. **Код уникален**: написан с нуля без использования готовых клонов.
2. **Экспериментальная часть**: сделайте в дипломе две серии тестов:
   - *Тест 1 (До защиты):* Запуск на стандартной Windows без дополнительных настроек (покажет много красных меток «Уязвимо»).
   - *Тест 2 (После защиты):* Включение в Windows LSA Protection и запрет прав на запись в реестр, повторный запуск (покажет рост защищенности до 80-90%).
3. **Графики и таблицы**: скриншоты дашборда и выгруженный HTML-отчет вставляются во 2-ю и 3-ю главы диплома.

> **Дипломный проект по специальности:** 10.05.01 «Компьютерная безопасность» / 10.03.01 «Информационная безопасность»  
> **Тема ВКР:** *«Разработка программного комплекса автоматизированного моделирования и эмуляции целевых компьютерных атак на основе матрицы MITRE ATT&CK»*

---

## 🎯 О проекте
Программно-аппаратный комплекс класса **Breach and Attack Simulation (BAS)**, предназначенный для непрерывной оценки эффективности корпоративных средств защиты информации (СЗИ, EDR, SIEM, антивирусов).

Комплекс в автоматическом режиме воспроизводит цепочки реальных хакерских техник вторжения, закрепления, обхода защиты и эксфильтрации данных, оценивает реакцию операционной системы и формирует объективный индекс защищенности (**Security Posture Score**).

### 🛡️ Гарантия безопасности (Safe Emulation & Cleanup)
Все сценарии атак разработаны по принципу **недеструктивной эмуляции**:
* Не повреждают системные файлы и рабочие данные.
* Каждый модуль содержит обязательный алгоритм **реверсивной зачистки следов (Cleanup)** — удаление канареечных ключей реестра, временных заданий планировщика и файлов сразу после фиксации результатов.

## 🗺️ Реализованные техники MITRE ATT&CK

| ID по MITRE | Название техники | Тактика | Что эмулируется |
| :--- | :--- | :--- | :--- |
| **T1082** | System Information Discovery | Discovery | Сбор сведений об ОС, ядре, патчах |
| **T1087** | Account Discovery | Discovery | Перечисление локальных пользователей |
| **T1057** | Process Discovery | Discovery | Поиск установленных антивирусов и СЗИ |
| **T1547.001** | Registry Run Keys | Persistence | Закрепление в ветке автозагрузки `CurrentVersion\Run` |
| **T1053.005** | Scheduled Task | Persistence / Execution | Регистрация фоновой задачи в Планировщике |
| **T1027** | Obfuscated Files / Info | Defense Evasion | Запуск закодированных Base64-команд в обход AMSI |
| **T1070.004** | Indicator Removal: File Deletion | Defense Evasion | Экстренное затирание дроппера для обхода форензики |
| **T1548.002** | Bypass User Account Control | Privilege Escalation | Анализ слабостей конфигурации UAC |
| **T1003** | OS Credential Dumping | Credential Access | Проверка доступности памяти LSASS и веток SAM |
| **T1048.003** | Exfiltration Over DNS | Exfiltration | Скрытая передача данных через протокол DNS |

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```powershell
pip install -r requirements.txt
```

### 2. Запуск интерактивной веб-панели (Web Dashboard)
```powershell
python main.py
```
* Откроется браузер по адресу: **http://127.0.0.1:8000**
* В интерфейсе доступен запуск сценариев, просмотр матрицы, живой терминал и кнопка **«Выгрузить отчет для ВКР (HTML)»**.

### 3. Запуск в чистой консоли (CLI Mode)
```powershell
python main.py --cli
```

### 4. Запуск автоматических тестов
```powershell
python -m unittest discover tests
```
